# Personal Portfolio Website

A cute, pink-themed personal portfolio website with an iPod music player UI and dancing cat animation.

## Features

- Soft pink, cream, and lavender (`#d8bfff`) color palette
- Cute iPod interface that links to R&B hits on [Jango Radio](https://www.jango.com/)
- Sticky mini iPod player with dancing cat that appears on scroll
- Responsive design for mobile and desktop
- Smooth scroll navigation

## How to Use

1. Open `index.html` in your browser
2. Click the play button (▶) on the iPod to start streaming R&B radio directly on the page
3. Click ⏩ on the iPod wheel to skip to the next station
4. Scroll down to see the sticky mini iPod and dancing cat appear in the bottom-right corner
5. The mini iPod also has play/pause controls

## Customization

- Edit `index.html` to update your name, projects, skills, and contact info
- Edit `styles.css` to tweak colors (CSS custom properties are at the top of the file)
- Replace placeholder project descriptions with your real work
